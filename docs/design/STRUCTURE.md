# MDS Manager — дизайн і структура веб-інтерфейсу

Чернетка для погодження. Клікабельний макет: `docs/design/manager-mockup.html`.

## Принцип

- **Дизайн — один на дві системи.** MDS Manager виглядає як MDS Connect: та сама палітра (темно-зелений
  `#14392c` + золото `#b48a3e`), шрифти Manrope і Cormorant Garamond, бічна панель, KPI-плитки, картки,
  сегменти, чипи, світла й темна тема, нижня панель вкладок на телефоні. Токени беремо з
  `ikenlo/m-d` → `server/mds/web/static/style.css`, не вигадуємо свої.
- **Усе керування — на сайті.** Адмінські команди Telegram (`/today`, `/reply`, `/gen`, `/sources`…) прибираємо.
  Telegram-група лишається лише для **сповіщень** з кнопкою «Відкрити на сайті».
- **Без дублювання з MDS Connect.** Записи, клієнти, каталог, гроші й SMS живуть у MDS Connect.
  MDS Manager їх показує і посилається туди, але не редагує.
- **Вхід — тим самим логіном, що в MDS Connect** (директор і адміністратор). Окремий пароль `/panel` прибираємо.

## Меню

| Група | Розділ | Що там | Замінює |
|---|---|---|---|
| Огляд | **Огляд** | Хто чекає відповіді, записи від AI, цифри за вчора, 3 дії від AI-аналітика, найближчі пости | `/panel`, `/stats` |
| Клієнти | **Діалоги** | Усі розмови Instagram і Telegram; стан «AI відповідає / Потрібна людина / Відповідає адміністратор»; відповідь клієнту з сайту; «Взяти на себе», «Повернути AI»; посилання на картку в MDS Connect | `/takeover` `/resume` `/reply` `/client` `/forget` |
| Маркетинг | **Статистика** | Вчора / тиждень / місяць: салон (MDS), Instagram, Facebook, реклама Meta і Google; кращі дні тижня; результати постів | `/sources` (частково) |
| | **Реклама** | Оголошення Meta і Google з ціною візиту й станом (окупається / дорого / без візитів); ідеї нових рекламних постів з текстом і промптами | — |
| | **Контент-план** | Календар місяця, пост — картка з підписом, хештегами, закликом, промптами для картинки й відео; «Згенерувати картинку», «Опубліковано» | `/panel/content` |
| | **Генератор** | Підписи, тексти оголошень, картинки за запитом | `/gen` `/image` |
| | **Посилання з мітками** | Посилання на бота з міткою для кожної реклами чи листівки + скільки записів і виручки дала | `/link` `/sources` |
| Система | **Витрати на AI** | Скільки витрачено з місячного ліміту, за видами | `/budget` |
| | **Налаштування** | Вимикач «AI відповідає клієнтам», звіти й план за розкладом, стан підключень (MDS, Instagram, Telegram, Meta, Google Ads, AI) | `/pause_all` `/resume_all` |
| Салон | **MDS Connect ↗** | Перехід у MDS Connect | `/today` `/book` `/cancel` `/move` `/noshow` `/done` `/dayoff` `/price` — це вже робиться в MDS Connect |

Телефон: вкладки **Огляд · Діалоги · Контент-план · Статистика · Ще**.

Права: директор бачить усе. Адміністратор бачить Огляд, Діалоги, Контент-план і Генератор,
але не бачить Рекламу, Витрати на AI й Налаштування.

## Що лишається в Telegram

- Адмін-група: «🔴 Ірина К. (Instagram): алергія — потрібна людина» з кнопкою **Відкрити діалог** (посилання на сайт),
  ранковий підсумок аналітика, помилки підключень.
- Клієнтський бот без змін: клієнти пишуть, AI відповідає, `/book` і `/my`.

## Як буде зроблено технічно

- Сервер MDS Manager віддає JSON API (`/api/...`) і статичну односторінкову панель, як у MDS Connect:
  `app.js` з `VIEWS` і `NAV`, DOM лише через `h()`, спільний `style.css`.
- Вхід: MDS Manager перевіряє логін через MDS Connect і бере звідти роль.
- Стара сторінка `/panel` і адмінські команди видаляються після того, як нова панель запрацює.
- Порядок робіт: 1) каркас, вхід, Огляд; 2) Діалоги (без них не можна прибрати `/reply`);
  3) Статистика й Реклама; 4) Контент-план і Генератор; 5) Посилання, Витрати, Налаштування;
  6) видалити команди і `/panel`.
