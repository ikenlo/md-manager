# Доступи для маркетингового модуля

Що оформити власнику, щоб помічник збирав аналітику й допомагав з рекламою.
Стан на 11.2026; правила платформ змінюються — перевіряйте посилання.

## Порядок (від найшвидшого)

| # | Що | Скільки чекати | Навіщо |
|---|---|---|---|
| 1 | **Google AI Studio**: проєкт, ключ Gemini API, **увімкнена оплата** | хвилини | дешеві тексти й картинки (`GEMINI_API_KEY`) |
| 2 | **Meta Business Manager**: рекламний акаунт + сторінка Facebook + Instagram professional, привʼязаний до сторінки. Meta-апка типу Business, **System User** з токеном (`ads_read`, `ads_management`, `business_management`, `pages_*`, `instagram_*`) | ~1 день, перевірка не потрібна | аналітика IG/FB, звіти й (з вашого «так») створення реклами |
| 3 | **Events Manager → набір даних Conversions API** | хвилини | передавати Meta, хто реально прийшов (офлайн-події) — реклама вчиться знаходити схожих |
| 4 | **Google Business Profile API**: форма доступу з номером Cloud-проєкту | 1–4 тижні | перегляди на картах, дзвінки, маршрути, відгуки |
| 5 | **TikTok for Business**: бізнес-акаунт → акаунт розробника → заявка на Marketing API і Accounts API | ~1–2 тижні | перегляди, залучення, реклама TikTok |
| 6 | *(за потреби)* **Перевірка бізнесу Meta + App Review** для `instagram_manage_events` | 1–3 тижні | події з Direct у Conversions API |

## Важливо

- **Gemini — лише платний тариф.** На безкоштовному Google використовує дані для покращення моделей;
  на платному — ні. Переписка клієнтів туди не повинна потрапляти.
- **Meta, свої акаунти:** перевірка апки (App Review) для аналітики й реклами власного салону **не потрібна** —
  вистачає базового рівня доступу. Нові оголошення помічник створює **на паузі**, запуск — лише після вашого «так».
- **Google Business Profile:** профіль має бути підтверджений і активний **60+ днів** і мати сайт.
- **Відео:** Veo в Gemini API вимкнено 22.10.2026; замість нього Gemini Omni Flash (~$0.07/с для 720p,
  10-секундний ролик ≈ $0.70). Промпти для відео — англійською (українська підтримується не повністю).
