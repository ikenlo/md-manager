# Як підключити Google AI Studio (Gemini)

Gemini у MDS Manager обробляє фото для контент-плану. Без нього фото можна брати «без обробки».
Займе 10–15 хвилин. Стан на 11.2026 — назви кнопок у Google можуть змінитися.

## 1. Створити ключ

1. Відкрийте **https://aistudio.google.com/api-keys** і увійдіть акаунтом Google салону
   (краще окремим робочим, не особистим).
2. Прийміть умови використання. Google сам створить проєкт і перший ключ.
   Якщо у вас уже був Google Cloud, проєкт не створиться: **Dashboard → Projects → Import projects**,
   оберіть проєкт → **Import**.
3. На сторінці **API Keys** натисніть **Create API key**, якщо ключа ще немає.
4. Обмежте ключ: біля ключа з позначкою «Unrestricted» → **Add restrictions** →
   **Restrict to Gemini API only** → **Restrict key**. Gemini не приймає запити від необмежених ключів.

## 2. Увімкнути платний тариф — обовʼязково

На безкоштовному тарифі Google використовує надіслані фото й тексти для покращення своїх моделей,
і їх можуть переглядати люди. Google сам пише: не надсилайте туди особисту інформацію.
Фото клієнток — саме такі дані. На платному тарифі Google їх для навчання не використовує.

1. На сторінці **API Keys** або **Projects** знайдіть свій проєкт у колонці **Billing Tier** →
   **Set up billing**.
2. Оберіть країну **Україна**, заповніть контакти й спосіб оплати.
3. Поповніть рахунок: **https://aistudio.google.com/billing** → **Buy credits**, мінімум **$5**.
   Кредити діють 12 місяців і не повертаються. Для контент-плану $5 вистачить надовго
   (≈ $0.03 за одне фото).
4. Коли кредити закінчуються, **усі ключі одразу перестають працювати**. Щоб не пропускати це,
   увімкніть **Setup auto-reload** з **Monthly Limit** або просто поповнюйте вручну.
5. Обмежте витрати: **https://aistudio.google.com/spend** → **Monthly spend cap** →
   **Edit spend cap**, наприклад $5 на місяць.

## 3. Вписати ключ на сервер

1. Скопіюйте ключ на сторінці **API Keys**. Ключ — як пароль: нікому не пересилайте,
   не вставляйте в чати й не комітьте в Git.
2. На сервері:
   ```bash
   cd ~/md-managment        # папка з проєктом
   nano .env
   ```
   Знайдіть рядок `GEMINI_API_KEY=` і вставте ключ одразу після `=`, без пробілів і лапок.
   Збережіть: Ctrl+O, Enter, Ctrl+X.
3. Перезапустіть застосунок:
   ```bash
   docker compose up -d
   ```

## 4. Перевірити

1. Відкрийте **https://<ваш-домен>/panel/content**. Напис «Обробка фото вимкнена» має зникнути.
2. Підтвердіть будь-яку ідею з фото — за хвилину зʼявиться «Після обробки AI».
3. Скільки витрачено, видно в блоці «AI цього місяця» на `/panel` і на
   https://aistudio.google.com/spend. Спільний ліміт на всі AI в системі — `AI_MONTHLY_BUDGET_USD` у `.env`.

## Якщо щось не так

| Що бачите | Що робити |
|---|---|
| «Gemini: помилка 402» | Закінчились кредити — поповніть на aistudio.google.com/billing |
| «Gemini: помилка 400 / 403» про ключ | Ключ скопійовано з пробілом або він не обмежений до Gemini API — див. крок 1.4 |
| «Місячний ліміт на AI …» | Спрацював `AI_MONTHLY_BUDGET_USD` — підніміть його в `.env` або зачекайте до 1-го числа |
| Ключ потрапив комусь у руки | Створіть новий ключ, впишіть у `.env`, перезапустіть, старий вимкніть на сторінці API Keys |

Джерела (11.2026): aistudio.google.com/docs/api-key, /docs/billing, /docs/terms, /docs/pricing,
/docs/available-regions — Україна є в списку доступних країн.
